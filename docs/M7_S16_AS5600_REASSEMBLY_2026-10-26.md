# M7-S16 AS5600 limits after reassembly — 2026-10-26

## Measured inputs
The user manually measured, with no new powered commissioning proof:

| Steering motor | MIN RAW | CENTER RAW | MAX RAW | Span RAW |
|---|---:|---:|---:|---:|
| LEFT | 2297 | 1873 | 1374 | 923 |
| RIGHT | 191 | 662 | 982 | 791 |

The LEFT RAW value falls from MIN to MAX; the RIGHT RAW value rises. Both CENTER positions are inside their own endstops, and neither new measured stroke crosses zero.

## Updated firmware source
On the existing `feature/m7-s15-ps2-controls-restoration-staged` branch, `Core/Src/main.c` now uses all six reported values. CENTER is a fixed compile-time target. MIN/MAX initialize the runtime RAM variables and can later be updated by a fully successful SELECT scan; no Flash persistence is provided.

The old calibration validator required RIGHT MIN RAW >=2200 and could not accept the new 191 count value. `Steering_PositionGeometryValid` now checks direction-dependent CENTER bracketing with at least 60 counts from each endpoint, a 250–1250 RAW total stroke, and unwrapped monotonic RAW values. This common check is used for both SELECT calibration acceptance and normal position acceptance. If a future sensor mounting crosses 4095 -> 0, the existing noncircular M7-S10 soft-limit logic needs redesign before such a scan can be accepted.

Existing M7-S10 manual soft clearance settings were **not changed**: LEFT has 100 RAW margin (SOFT_MIN 2197, SOFT_MAX 1474); RIGHT has 40 RAW margin (SOFT_MIN 231, SOFT_MAX 942). Coasting clearance has not been verified on hardware after reassembly.

The S11 strict global AS5600 hard-envelope checker now uses each motor's NEW CENTER as signed shortest-delta reference and NEW MIN/MAX with 8 RAW tolerance. It additionally rejects invalid geometry. The separate 64-RAW range used by bounded position/escape algorithms is preserved. Unexpected NC contact and AS5600 communication faults still stop the vehicle. Arming is unchanged and remains disabled at boot: `steer_safety_motion_permit=0`, `steer_manual_enable=0`, `steer_pos_enable=0`, `steer_cal_arm=0`.

The S16 RIGHT-reference / LEFT-follower AS5600 speed PI, wheel PI+FF, PS2 decode, R1/R2, SELECT, Voice, RAM logger and incident trace remain in the firmware. The reported RIGHT self-motion at zero MCU PWM is not resolved by replacing geometry.

If cc/gcc/clang is installed the script extracts the actual C geometry and hard-envelope helpers and runs 22 host test cases. Run `python tools/verify_ps2_restore.py` and `python tools/test_steering_speed_sync.py` for other regression checks.

This update was committed and inspected at source level, but no STM32CubeIDE target build or motor-powered hardware acceptance has been verified.
